# 业务集合设计（uniCloud 阿里云）

本目录下的 `*.schema.json` / `*.index.json` / `*.init_data.json` 遵循 HBuilderX 约定：
右键 `database` 目录 →「初始化云数据库」即可一次性建表、建索引并导入示例数据，无需在控制台手动操作。

所有业务集合的 schema 权限均为 `false`（客户端不可直接读写），只能经由 `userService` / `telemetryIngest` 云函数访问。

| 集合 | 写入方 | 索引 | 示例数据 |
|---|---|---|---|
| `robots` | 初始化数据 / `admin-robot` | `robotCode` 唯一 | ROBOT-001、ROBOT-002 |
| `robot_bindings` | `userService.bindRobotForTest / unbindRobot` | `uid + robotCode`、`robotCode` | — |
| `telemetry_latest` | `telemetryIngest`（按 robotCode upsert） | `robotCode` 唯一 | — |
| `telemetry_history` | `telemetryIngest`（每次上报追加） | `robotCode + ts↓` | — |
| `commands` | `userService.sendCommand` | `robotCode + ts↓` | — |
| `faults` | 初始化数据 / 外部系统 | `robotCode + ts↓` | 3 条（2 条未解决） |

---

## robots

| 字段 | 类型 | 说明 |
|---|---|---|
| `robotCode` | string | 机器人编号，唯一，绑定时输入的就是它 |
| `model` | string | 型号 |
| `location` | object `{x, y}` | 初始位置；遥测里没有坐标时作为兜底展示 |
| `createTime` / `updateTime` | number | 毫秒时间戳 |

## robot_bindings

| 字段 | 类型 | 说明 |
|---|---|---|
| `uid` | string | 绑定用户（仅后端从 token 解出，前端无法指定） |
| `robotCode` | string | 机器人编号 |
| `status` | string | `active` / `inactive`；同一 robotCode 同时只能有一个 active 绑定 |
| `source` | string | 绑定来源 |
| `bindTime` / `unbindTime` | number | 毫秒时间戳 |
| `createTime` / `updateTime` | number | 毫秒时间戳 |

## telemetry_latest / telemetry_history

由 `telemetryIngest` 写入，两者字段相同：latest 每台机器人一条，history 每次上报一条。

| 字段 | 类型 | 说明 |
|---|---|---|
| `robotCode` | string | 机器人编号 |
| `vehicleBattery` | number | 车体电量 0–100 |
| `packBattery` | number | 电池包电量 0–100 |
| `speed` | number | 速度；`> 0` 时任务状态显示「行驶中」 |
| `x` / `y` | number | 坐标（可选） |
| `ts` | number | 设备侧时间戳 |
| `receivedAt` | number | 云端接收时间；**`now - receivedAt ≤ 15s` 判定为在线**，离线时拒绝下发指令 |
| `rawJson` | string | 原始上报内容 |
| `createdAt` / `updatedAt` | number | 毫秒时间戳 |

## commands

| 字段 | 类型 | 说明 |
|---|---|---|
| `uid` | string | 下发用户 |
| `robotCode` | string | 目标机器人 |
| `type` | string | `move` / `stop` / `goto`（白名单） |
| `action` | string | `velocity` / `stop` / `goto`，以及兼容旧协议的 `forward` 等 |
| `params` | object | move：`{vx, vy, wz, enable}`（均在 −1~1）；goto：`{x, y}`；stop：`{}` |
| `requestId` | string | 请求追踪 ID，透传给 Gateway |
| `status` | string | `pending` → `sent`（Gateway 返回 code 0）或 `failed` |
| `errorMessage` | string | 失败原因 |
| `bridgeHttpStatus` / `bridgeCode` / `bridgeMessage` | — | Gateway 响应摘要 |
| `ts` / `createTime` / `updateTime` / `sentTime` | number | 毫秒时间戳 |

## faults

详情页展示该机器人 **未解决**（`status != 'resolved'`）的最近 20 条故障。

| 字段 | 类型 | 说明 |
|---|---|---|
| `robotCode` | string | 机器人编号 |
| `code` | string | 故障代码 |
| `level` | string | `info` / `warn` / `error` |
| `message` | string | 故障描述 |
| `status` | string | `active` / `resolved` |
| `time` | string | 发生时间（展示用） |
| `ts` | number | 毫秒时间戳（排序用） |
| `createTime` / `updateTime` | number | 毫秒时间戳 |
